Express Server
A simple, lightweight Node.js web server built using Express.

Features
Fast and minimalist web server setup.

Runs on Port 3000 by default.

Includes a built-in startup log to confirm when the server is live.

Getting Started
Prerequisites
Make sure you have Node.js and npm installed on your machine.

Installation
Clone or download the project files.

Initialize or install dependencies (ensure express is installed):

Bash
npm install express
Running the Server
Start the server by running:

Bash
node index.js
Once running, you should see the following message in your terminal:

Server is running successfully on port 3000
